<h3 align="center">Your terminal, with context.</h3>

<p>
  A lightweight CLI tool for documenting your servers, VMs, and Linux instances.
</p>

<p>
  Termnote helps you remember what each instance is used for. Attach notes to
  your machines and access them directly from your terminal, so you always
  know what's running where and what each system is responsible for.
</p>
