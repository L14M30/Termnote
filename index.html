Installing via CURL

Run the following command! It is recommended NOT to use SUDO or Root privileges. Instead you will be asked for root privileges during installation.

curl -fsSL https://github.com/L14M30/Termnote/releases/download/Latest/termnote_release_v.X_X_X_linux.sh | bash

Replace v.X_X_X with the latest version number. Which you can find here: Releases
